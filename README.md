# Nosso Projeto

Projeto desenvolvido para a faculdade.

## Descrição

Este projeto terá como base uma ONG localizada no centro de Niterói, que ajuda as crianças que se encontram em situação de vulnerabilidade social nas periferias por meio de artes marciais, como o jiu-jitsu e o Muay Thai. O projeto contará com um sistema completo contendo front-end e back-end, e seu objetivo é ser um facilitador para as pessoas que desejam fazer cadastro (log-in), e com isso poderem agendar horários para fazer uma aula, caso seja do interesse do aluno. Teremos um banco de dados para armazenar as respectivas informações dos que desejam se matricular. O sistema funcionará normalmente, não só para as crianças interessadas, mas também a todos que demonstrarem interesse em conhecer e visitar o local, o site pode ser até mesmo um meio de propagação para os que nunca tinham ouvido falar da instituição.

## Tecnologias utilizadas

* HTML
* CSS
* Python
* MYSQL
* GitHub

## Instruções de uso

1. Acesse o sistema do projeto.
2. Realize o cadastro (log-in) para poder utilizar as funcionalidades disponíveis.
3. Após o cadastro, o usuário poderá agendar um horário para realizar uma aula, caso tenha interesse.
4. O sistema armazenará as informações dos usuários que desejarem se matricular em um banco de dados.
5. O sistema também poderá ser utilizado por pessoas interessadas em conhecer e visitar o local.
